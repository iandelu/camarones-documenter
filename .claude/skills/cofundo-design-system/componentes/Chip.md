# Chip

`co-chip`: etiqueta pequeña en píldora, mayúsculas de 11px y borde `color-rule`, para marcar un dato al lado de otro («Tú», «No consume asiento», un estado de producto).

- **Cuándo**: para calificar un elemento de una lista o una tarjeta. No es un botón ni un filtro: no se pulsa.
- **Qué pones tú**: un `<span class="co-chip">` con una o dos palabras. El estado de un producto sale del dato (`ETIQUETA_ESTADO`), nunca escrito a mano.
- **Color**: texto `color-ink-dim` sobre el fondo que tenga debajo; no se rellena de color.
