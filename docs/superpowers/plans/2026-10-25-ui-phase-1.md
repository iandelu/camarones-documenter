# UI redesign, phase 1: the portal as a reader, 100% React — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plain-script portal (`public/legacy/*.js`, ~2 000 lines) with React views on one shell
(persistent sidebar, header with the stacked brand, breadcrumbs, ⌘K), one view per commit, the portal working after
every commit.

**Architecture:** The shell comes first and owns the chrome and the hash router (`src/router.js`, pure and tested).
For a view not migrated yet it calls the legacy function through a bridge (`window.CamaronLegacy`), which still
paints into `#main`, `#toc` and `#tree` — slots the shell renders and never re-renders. Each later commit moves one
view to React, routes it natively and deletes its legacy code. The last commit deletes `public/legacy/` and the bridge.

**Tech Stack:** React 19, Vite 8, Vitest 5 (node env, static markup), the kit `@camaron/ui` (phase 0). pytest for the
served portal and the static export.

**Design:** approved plan `~/.claude/plans/quiero-un-plan-para-atomic-dragon.md`, canvas
https://claude.ai/artifact/6Ppc9GNwMS4gUikBqPpVr2. Phase 0: `docs/superpowers/plans/2026-10-25-ui-phase-0.md`.

Branch `redesign/ui`, worktree `.claude/worktrees/redesign-ui`.

## Global Constraints

- Hash addresses do not change: `#/docs/<path>::<anchor>`, `#/doc/…`, `#/wiki/<repo>/<rel>`, `#/wikis/<repo>`,
  `#/c4/<view>`, `#/code/<repo>`, `#/review`, `#/status`, `#/search/<q>`, `#/ask/<q>`, `#/new`, zone covers, the
  `#/boards…` → `#/arch` redirect. `router.test.js` locks each one before the shell replaces `routeNow`.
- Three modes keep working: `static` (export, `meta cam-mode`), `live`, `app` (desktop window, Taller). The Taller
  stays in the portal until phase 2 gives the desktop app its own renderer.
- Same API calls (`lib/serve.py` untouched unless a test asks for it). Same `localStorage` keys (`cam-lang`,
  `cam-theme`, `cam-audience`).
- Strings in es and en; labels keep their i18n keys (legacy `core.js` I18N until the dictionaries move to `src/`).
- Pending on `main` (uncommitted in the main checkout when this was written): the desktop header as the window's
  title bar (`.in-app`) and the ⋯ app-menu button. Port both into the shell when they land on `main`.
- Each commit rebuilds and commits `app-build/`; `uv run pytest tests/test_portal_app.py tests/test_portal_data.py
  tests/test_portal_smoke.py` green, `npm test` green.
- User-visible changes update README/tutorial in the same commit (AGENTS §5.1); bump `VERSIONS["kit"]` at the end.

## Tasks (one commit each)

1. **Shell + router.** `src/router.js` (`parse`, `resolve`) with characterization tests of every address above.
   `src/shell/Shell.jsx`: header (Brand, Breadcrumbs from `zones.crumbs`, search button, trust chips with words,
   language, theme), persistent sidebar (zones of the mode; the docs tree slot under Docs), the main/toc slots, the
   read-only banner. `main.jsx` mounts the shell; `Native` renders inside it. `app.js` loses chrome, routing and boot;
   it exposes its views as `window.CamaronLegacy`. Python tests that grep `app.js` follow the move.
2. **Home and zone covers** (`showStart`, `showZone`, empty project) → `Home.jsx`, `Zone.jsx`.
3. **Search** (palette + `#/search`) → `Palette.jsx` (listbox roles, `aria-activedescendant`), `Search.jsx`.
4. **Review** → `Review.jsx` with bulk confirm.
5. **Doc page** (`showDoc`, `showPage`, confirm, feedback, edit, new page) → `Doc.jsx` + `content/render.js` (the
   markdown pipeline of `doc.js` as a module), TOC, pager, sources panel.
6. **Docs home and tree** → `DocsHome.jsx`, `DocsTree.jsx`.
7. **Wikis** (`wiki.js`) → `Wikis.jsx`.
8. **C4** (`c4.js`) → `C4.jsx`, LikeC4 web component kept.
9. **Code map** (`code.js`) → `CodeMap.jsx`, graph colours from tokens.
10. **Remove legacy**: delete `public/legacy/*.js`, `app.css` folded into `src/`, the bridge, the `<script defer>`
    tags; Python tests updated; `VERSIONS["kit"]` bump, README + tutorial.

- Browser pane on `uv run scripts/sandbox.py cli up` (or the static export): the migrated view in light/dark, at
