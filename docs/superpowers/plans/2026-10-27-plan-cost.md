# Plan Cost Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `camaron plan cost`, and a card in the desktop app's Plan and the portal's KPIs, showing the tokens, time and
API-equivalent dollars the current documentation plan took from zero, for the whole team.

**Architecture:** Three new harness modules — `pricing` (price table), `transcripts` (Claude Code transcript → tokens and
active time), `ledger` (harvest sessions into the machine's KPIs roll-up; build the team's bill). Runs gain a per-unit
breakdown in the roll-up, wikis through an agent runner write a run log of their own, and `plan.yaml` gains an epoch.
One shared UI component (`@camaron/ui`) renders the bill in both apps.

**Tech Stack:** Python 3.10+ (stdlib + PyYAML), pytest (+xdist); React + Vite + Vitest for the apps.

**Spec:** `docs/superpowers/specs/2026-10-27-plan-cost-design.md`

## Global Constraints

- macOS, Windows and Linux: `pathlib` only; `encoding="utf-8"` on every read/write; text written with `newline="\n"`;
  no `shell=True`; branch on `IS_WIN`/`IS_MAC` only.
- TDD: the failing test first. Tests offline and deterministic: `make_workspace`, the `kit`/`wired`/`isolated_env`
  fixtures; never the real `~/.camarones` or `~/.claude`.
- Run the suite with `uv run pytest -n auto`; a single file without `-n`.
- Only new, optional keys: `epoch` (plan.yaml), `by_unit` and `sessions` (KPIs roll-up), `model` (usage events),
  `previous` (session record). The roll-up keeps `"v": 1`. **`runs.<id>.units` is an existing integer — never reuse it.**
- A missing price or an unmeasured session is `null`/listed, never 0. Local models (`routing.LOCAL_PROVIDERS`) cost 0.
- Stats code never fails a run, a `plan done` or a wiki: every exception in it is swallowed.
- Roll-up writes: only when usage stats are on, under `FileLock(CACHE / "locks" / "kpis.lock")`, atomic, and only when
  the content changed.
- `GET /api/plan/cost` never writes; `POST /api/plan/cost` needs the app token.
- UI strings in `es` and `en`; no jokes on these screens or in `--json`. CLI report text in English, like `kpis`/`runs`.
- `VERSIONS["kit"]` → `"4.68.0"`; README badge to match.
- Conventional commits; no Co-Authored-By or "Generated with" lines; stage only this work's hunks.

## Review Focus

- A transcript still being written ends in a half line: it is ignored, never a crash or a lost total (Task 2 test).
- Timestamps come as `…Z`, `…+00:00` and naive local ISO (plan's `now()`): comparing them never raises; naive counts
  as local time (Task 7 test).
- A unit no longer in the plan (repo removed, flow dropped) still gets its phase from its type prefix, or "other"
  (Task 7 test).
- A route to a local model (`opencode:ollama/qwen3-coder:30b`) prices at $0, not "unpriced" (Task 1 test).
- A teammate's roll-up with `sessions` or `by_unit` that is not a dict (hand-edited, merge-damaged) is skipped with a
  note, and the rest of the bill still adds up (Task 7 test).

**Interfaces:**
- Produces:

  - `table(workspace: dict | None = None) -> tuple[dict, list[str]]` — the kit table merged per key with
    `workspace["pricing"]` (`models`, `aliases`, `runners`); returns `(table, problems)`, each problem a text naming the

    else None.
  - `cost(tokens: dict, model: str | None, runner: str | None, tbl: dict) -> float | None` — tokens keyed by `KINDS`
    (a legacy `cache_write` counts as `cache_write_5m`; missing kinds are 0); prices are USD per million tokens;
    `0.0` for `"local"`; None when unresolved. Rounded to 6 decimals.

### Task 2: Claude Code transcripts

**Files:**
- Create: `.camarones/lib/harness/transcripts.py`
- Test: `tests/test_transcripts.py`

**Interfaces:**
- Produces:
  - `IDLE = 300`
  - `files(path: Path) -> list[Path]` — the transcript (if it exists) plus `path.with_suffix("") / "subagents" / "*.jsonl"`, sorted.
  - `size(path: Path) -> int` — total bytes of `files(path)`; 0 when none.
  - `read(path: Path) -> dict | None` — None when the transcript does not exist; else
    `{"models": {<model>: {"in", "out", "cache_read", "cache_write_5m", "cache_write_1h"}}, "first": str | None,
    "last": str | None, "active_seconds": float, "bytes": int}`.

Rules (spec §4.2): only `type == "assistant"` lines count tokens, once per `message.id` (a line with no id counts on
its own); the 5m/1h split from `usage.cache_creation`, else all of `cache_creation_input_tokens` is 5m; subagent files
add tokens but not time; `first`/`last`/`active_seconds` come from the main file's `timestamp`s only, each gap capped at
`IDLE`; damaged lines and a trailing line without `\n` are skipped. Stream line by line (`open(..., "rb")`), never
`read_text()` on the whole file.

    - `people`: distinct person part (before the last `-`) of the roll-up file stems with in-plan entries, plus

    - `complete`: no unpriced and no unmeasured.
