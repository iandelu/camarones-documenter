# UI redesign, phase 0: the shared kit `.camarones/ui` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One place for the theme, the base React components and the shared strings, so the portal (reader) and the
future desktop renderer (operator) look like one product while being two apps.

**Architecture:** `.camarones/ui/` holds `theme/` (tokens.css + self-hosted fonts, moved from
`portal/app/public/theme/`), `src/` (React components + `ui.css`) and `i18n/`. It has no build and no `package.json`:
each app's Vite imports it through the alias `@camaron/ui` and dedupes `react`, so `ui/` resolves React from the app.
A small Vite plugin serves `ui/theme/` at `/theme/` in dev and copies it into the build, so every published URL
(`theme/tokens.css`, `theme/fonts/*.woff2`, the hub's `../../portal/app-build/theme/tokens.css`) stays the same.

**Tech Stack:** React 19, Vite 8, Vitest 5 (node environment; components are tested with
`react-dom/server.renderToStaticMarkup`, no new dependency). pytest for the served routes.

**Design:** the approved plan `~/.claude/plans/quiero-un-plan-para-atomic-dragon.md` and the canvas
https://claude.ai/artifact/6Ppc9GNwMS4gUikBqPpVr2 (square radii, stacked brand, breadcrumbs, little text).

Work in the worktree `.claude/worktrees/redesign-ui` (branch `redesign/ui`): another session has uncommitted portal
edits in the main checkout.

## Global Constraints

- macOS, Windows and Linux: paths in the Vite plugin via `node:path`/`node:url`, never string concatenation with `/`.
- No served URL changes: `tests/test_portal_app.py` keeps passing untouched (`/theme/tokens.css`, fonts).
- No raw colours, no emoji, no `vh` in `ui/` (tests enforce it). Every component string in `es` and `en`.
- Radii: square, as validated in the canvas. Token values change (`--radius-*`, `--consola-radio-*`); legacy rules
  with hard-coded radii stay until phase 1 migrates them.
- Nothing a user notices beyond squarer corners: say so in the commit body (AGENTS §5.1), no README/tutorial change.
